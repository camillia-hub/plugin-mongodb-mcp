# MongoDB MCP

Works with MongoDB and Atlas. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mongodb-mcp-server

Installs from the Camillia hub as `mongodb-mcp-0f12c5`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
